## 1. 最重要ルール

### 1-1. ハルシネーション禁止

以下を絶対に守ること。

- 不明な仕様を勝手に補完しない
- 存在不明の関数、クラス、列挙値、APIを書かない
- MQL4とMQL5を混同しない
- 実装していない機能を実装済みのように書かない
- 不明な箇所は「不明」と明記する
- 仮定が必要な場合は「仮定」と明記する
- 仕様とコードを必ず一致させる

### 1-2. 禁止事項

- ナンピン
- マーチンゲール
- 無限平均化
- 損切りなし
- 裁量依存表現
- バックテストだけ良く見せる過剰最適化
- 擬似コードだけの出力
- 省略コード
- 未定義関数を残すこと

### 1-3. 曖昧表現禁止

以下のような表現は禁止。

- いい感じのトレンド
- 強そうなら買う
- 伸びそうなら持つ
- 適宜利確
- 相場状況に応じて判断
- ケースバイケース

すべて**EAが機械的に判定できる条件式**にすること。

## 3. 固定ロジック仕様

以下の数値を基本固定値として採用すること。
ただし、最終コードではinput化し、初期値として設定すること。

### 3-1. インジケータ設定

#### D1

- EMA短期：**20**
- EMA長期：**60**
- ADX期間：**14**
- ATR期間：**14**

#### H4

- EMA短期：**20**
- EMA長期：**60**
- ADX期間：**14**
- ATR期間：**14**

### 3-2. D1トレンド判定

#### 上昇トレンド条件

以下をすべて満たした場合のみ、D1上昇トレンドと判定すること。

1. EMA20 > EMA60
2. EMA20[1] > EMA20[3]
3. EMA60[1] > EMA60[3]
4. 直近3本の確定足において、安値の切り上がり傾向がある
5. ADX(14) >= **23**
6. ATR(14) / Close >= **0.0045**

#### 下降トレンド条件

以下をすべて満たした場合のみ、D1下降トレンドと判定すること。

1. EMA20 < EMA60
2. EMA20[1] < EMA20[3]
3. EMA60[1] < EMA60[3]
4. 直近3本の確定足において、高値の切り下がり傾向がある
5. ADX(14) >= **23**
6. ATR(14) / Close >= **0.0045**

#### それ以外

- レンジまたは見送り

## 4. H4執行ロジック

### 4-1. H4買い条件

以下をすべて満たした場合のみ買いを許可すること。

1. D1が上昇トレンド
2. H4で EMA20 > EMA60
3. H4のEMA20[1] > EMA20[2]
4. H4のADX(14) >= **20**
5. H4のATR(14) / Close >= **0.0022**
6. 直近3本以内で一度EMA20付近まで押している  
   条件例：直近3本のいずれかの安値が EMA20 から **0.35ATR以内**
7. 最新確定足が陽線
8. 最新確定足の終値がEMA20より上
9. 最新確定足の高値が、その1本前の高値を上抜いている
10. 直近20本高値までの余地が、初期SL幅の **1.5倍以上**
11. スプレッドが上限以下
12. 停止条件に該当していない
13. 同一シンボルで買いポジションを保有していない
14. 直前決済から**2本以内の再エントリーではない**

### 4-2. H4売り条件

以下をすべて満たした場合のみ売りを許可すること。

1. D1が下降トレンド
2. H4で EMA20 < EMA60
3. H4のEMA20[1] < EMA20[2]
4. H4のADX(14) >= **20**
5. H4のATR(14) / Close >= **0.0022**
6. 直近3本以内で一度EMA20付近まで戻している  
   条件例：直近3本のいずれかの高値が EMA20 から **0.35ATR以内**
7. 最新確定足が陰線
8. 最新確定足の終値がEMA20より下
9. 最新確定足の安値が、その1本前の安値を下抜いている
10. 直近20本安値までの余地が、初期SL幅の **1.5倍以上**
11. スプレッドが上限以下
12. 停止条件に該当していない
13. 同一シンボルで売りポジションを保有していない
14. 直前決済から**2本以内の再エントリーではない**

## 5. エントリー禁止条件

以下のいずれかに該当したら新規エントリー禁止。

1. D1トレンド不明
2. H4でEMA20とEMA60の距離が近すぎる  
   条件：|EMA20 - EMA60| < **0.20ATR**
3. H4のADX(14) < **20**
4. H4のATR(14) / Close < **0.0022**
5. RRが **1.5未満**
6. スプレッド超過
7. 日次停止中
8. 週次停止中
9. 連敗停止中
10. 同一バー内再判定
11. 重要停止フラグON
12. 金曜深夜などの取引禁止時間帯
13. 直近の高値/安値が近すぎて、初期TP余地が不足
14. エントリー足が長い上ヒゲ・下ヒゲで失速形状の場合（実体が全体レンジの **35%未満**）

## 6. SL / TP / 建値移動 / トレーリング

### 6-1. 初期SL

#### 買い

以下の大きい方を採用すること。

- エントリー価格 - **1.6ATR**
- 直近5本の最安値 - **0.15ATR**

#### 売り

以下の小さい方を採用すること。

- エントリー価格 + **1.6ATR**
- 直近5本の最高値 + **0.15ATR**

### 6-2. 初期TP

- 初期TP = **エントリー価格からSL幅の1.8倍**
- つまり固定RRは基本 **1.8**

### 6-3. 建値移動

- 含み益が **+1.0R** に到達したら、SLを建値へ移動
- 建値移動は1回のみ
- 建値移動済みフラグを内部管理すること

### 6-4. トレーリング

- 建値移動後のみ有効
- ATRベーストレーリングを採用
- 買いの場合：新しいSL候補 = 現在価格 - **1.2ATR**
- 売りの場合：新しいSL候補 = 現在価格 + **1.2ATR**
- ただし、既存SLより不利な方向には動かさない

### 6-5. 時間切れクローズ

- **12本（H4で48時間）経過しても +0.5R 未満** の場合は成行決済
- ダラダラ保有を禁止すること

## 7. リスク管理

以下を固定初期値として採用し、input化すること。

- 1トレード最大損失：**口座残高の1.0%**
- RR最低基準：**1.5**
- 初期TP倍率：**1.8R**
- 日次停止：**-2.0%**
- 週次停止：**-4.0%**
- 連敗停止：**3連敗**
- 同時保有数：**1シンボル1ポジション**
- 全体最大同時保有数：**3**
- 金曜新規停止時刻：**サーバー時刻 20:00以降**
- 月曜早朝回避：**サーバー時刻 02:00までは新規停止**
- スプレッド上限：USDJPY **2.0 pips** / EURJPY **2.5 pips** / GBPJPY **3.0 pips**

### ロット計算

- 固定ロットは禁止
- **SL幅と口座残高1%から逆算したロット**を採用
- 最小ロット、ロット刻み、最大ロットはシンボル仕様に従う
- 算出不能時はエントリーしない
